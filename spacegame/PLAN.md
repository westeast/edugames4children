# ORBIT · 漫游宇宙 · 感知地球 — 太空学院

严格参考 [ORBIT (dididaiqu.com/orbit)](https://dididaiqu.com/orbit/) 的信息结构与交互模式，重写为**教育类宇宙探索游戏**。无图片资源，全部程序化纹理。

## 三种模式

| 模式 | 说明 |
|------|------|
| **自由探索** | 拖动旋转、滚轮/双指缩放、点击天体飞入。4 个探索尺度：近地轨道 / 太阳系 / 银河系 / 星系图鉴 |
| **任务模式** | 5 关主线，每关：前往目标 → 到达观察 → 回答问题 → 解锁知识卡 |
| **一键导览** | 5 站旅程，约 45 秒，含思考题与提示 |

## 5 关任务

| 关 | 标题 | 目标 | 教学点 |
|----|------|------|--------|
| 1 | 最近的邻居 | 月球 | 逃逸速度与大气 |
| 2 | 红色星球 | 火星 | 氧化铁致红 |
| 3 | 巨大的风暴 | 木星 | 大红斑 |
| 4 | 环的世界 | 土星 | 土星环成分 |
| 5 | 飞向星际 | 旅行者1号 | 金唱片 |

## 架构

```
spacegame/js/
  game.js       - 入口：状态机(explore/mission/tour) + 主循环 + 全局钩子
  engine.js     - Three.js 渲染器、相机、光照、星空、深空颜色
  config.js     - 天体数据/尺度层级/5关任务/5站导览/知识卡/全局状态
  celestial.js  - 太阳系(太阳+8行星+月球+土星环)、银河粒子旋臂、星系图鉴
  camera-rig.js - ORBIT 式缩放相机：拖动旋转/滚轮缩放/飞向天体/尺度切换
  ui.js         - 信息面板、目的地坞(搜索)、尺度导轨、图层、3D标签投影、任务/导览/知识卡
  mission.js    - 关卡任务：前往→到达→答题→知识卡
  tour.js       - 一键导览 5 站
  audio.js      - Web Audio 合成音效
```

## 参考 ORBIT 的对应实现

| ORBIT 元素 | 本作实现 |
|-----------|---------|
| 顶栏 类别/英文名/名称+编号/描述 | `#info-panel`（eyebrow / en / h1+index / desc）|
| 平均直径 / 公转周期 | `#info-stats`（真实数据）|
| 看万家灯火 / 探访空间站 | `#info-actions`（地球的操作按钮）|
| 探索尺度 导轨 | `#scale-rail` + 顶部 `#scale-nav` |
| DESTINATIONS 目的地 + 搜索 | `#dock`（`查找天体` 搜索）|
| 拖动旋转 · 滚轮缩放 · 点击前往 | camera-rig |
| 时间流速 / 轨道 / 标记 / 卫星 | `#layers` 图层开关 |
| 一键导览 · 5 站 · 约 40 秒 | tour.js（5 站 + 思考题）|
| 到站探索 · 换个角度想一想 | tour 卡 / mission 答题 |
| 深空颜色 / 深空星星 | 设置弹窗 |

## 交互

- 拖动旋转 · 滚轮/双指缩放 · 点击天体/坞条目飞入
- `空格` 暂停 · `H` 回地球 · `F` 全屏 · `+/-` 缩放 · `Esc` 关设置
